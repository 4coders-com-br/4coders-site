# 4coders.com.br

Institutional website for 4coders — Tech Education.

## Stack
- Pure HTML/CSS/JS (static site)
- Bilingual PT/EN with client-side toggle
- Hosted on DigitalOcean App Platform

## Deploy
Auto-deploys from `main` branch via DigitalOcean App Platform.

## Development
Open `index.html` in a browser, or use any static file server:
```
npx serve .
```
